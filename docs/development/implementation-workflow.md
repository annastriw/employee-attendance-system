# Alur implementasi

Panduan utama: [SDD, Kanban dan development](../development.md). Aturan testing: [unit wajib, integrasi cepat bila perlu, UI manual](../testing/workflow.md). Branch/rilis: [CI/CD](ci-cd-workflow.md).

Satu increment aktif dikerjakan serial. Baca baseline/module/source, tetapkan kontrak, implementasikan ujung ke ujung, verifikasi bagian berubah, update spesifikasi dan task, lalu commit/push dev. Main melalui PR setelah CI dan penerimaan scope rilis.

Handoff aktif: [docs/temporary/task/handoff.md](../temporary/task/handoff.md). Jangan menimpa source/perubahan pengguna atau mengklaim test/proses/akses tersedia dari catatan sesi lama.
